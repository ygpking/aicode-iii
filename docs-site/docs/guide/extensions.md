# 扩展（贡献 manifest）

扩展是**声明式资源包**：一个目录 + 一份 `manifest.json`，向 agent 的能力机制批量贡献技能、提示词片段、记忆、子代理与 MCP 配置。不含可执行代码——跨沙箱分发可执行代码在 Android 上不可行，扩展只搬资源。

## 目录约定

两级扩展根，与技能/记忆/MCP 的「全局/项目」两级一致：

```
~/.aicode/extensions/<extId>/            全局（跨项目）
<workspace>/.aicode/extensions/<extId>/  项目级（随工作区，可 git 追踪）
  ├─ manifest.json
  ├─ skills/<skill-dir>/SKILL.md
  ├─ prompts/30-<名称>.md
  ├─ memory/<name>.md
  ├─ agents/<name>.md
  └─ mcp.json
```

## manifest.json

```json
{
  "id": "my-pack",
  "name": "My Pack",
  "version": 1,
  "description": "一句话说明",
  "contributes": {
    "skills": ["skills"],
    "prompts": ["prompts"],
    "memory": ["memory"],
    "agents": ["agents"],
    "mcp": "mcp.json"
  }
}
```

- `id` 必填，`[a-z0-9-]`；非法时按目录名修正并在扩展错误中标注。
- `contributes` 各路径**相对于扩展根**，解析时校验不越界：越界的贡献被跳过、记入该扩展的错误清单，不影响其它扩展。
- 任一字段可省略：省略即不贡献该类。

## 层叠次序（近者胜）

| 层 | 优先级 |
| --- | --- |
| `prompts.custom/`（用户显式覆盖） | 最高 |
| 项目级扩展 | ↑ |
| 全局级扩展 | ↑ |
| 项目级内置目录 | ↑ |
| 全局内置目录 | 最低 |
| APK 内置资源 | 基线 |

- 技能/记忆同名：项目 > 全局、扩展 > 内置（后者胜）。
- 子代理同名：先看作用域（项目 > 全局），同作用域内扩展 > 目录。
- 提示词数字片段：custom 覆盖扩展覆盖内置；扩展的新增数字片段并入静态基线按数字排序。
- MCP server 同名：项目侧（含项目扩展）覆盖全局侧。扩展贡献的 server 会真实进「设置 → MCP」列表并参与连接，带「来自扩展」标签；与子代理不同，它是**完全只读**——不能编辑、不能删除，启停开关也置灰（它的启用状态存在扩展包的 mcp.json 里，要停用请改那里的 `enabled`，或卸载该扩展）。绕过界面直接改同样会被拒。扩展包的 mcp.json 格式是 `{"名称": {"command": ...}}`，无外层 `mcpServers`。
- `prompts.custom/.no-builtin`（完全禁用内置）不影响扩展：扩展是用户主动安装的内容，保留生效。

## 管理与故障排查

- **设置 →「AI 配置」→「扩展」**可查看已安装的扩展：按「当前项目 / 全局」分组列出名称、版本、贡献摘要与作用域；解析出错的扩展会在行内红字列出具体问题。左滑或点删除可移除整个扩展目录（不可恢复），删除后立即刷新列表。
- 扩展贡献的子代理同样出现在设置 →「子代理」列表，带「来自扩展」标签。它们的**定义本体只读**（名称、提示词、工具集、注入项都改不了）——要改这些就改扩展目录里的定义文件（或卸载整个扩展）。但**模型可以单独设置**：进详情页点右上角编辑，页面只展示「模型」与「思考强度」两项，保存后写进 `agents.json` 的覆盖表，不动扩展文件，扩展升级也不会丢。从列表、详情页或 AI 侧绕过界面去改本体同样会被拒，并提示该定义由扩展提供。
- 扩展目录的增删改（装包、删包、改 manifest）会在数秒内自动刷新设置页的技能/记忆/子代理/扩展列表，不需要重进页面。
- 扩展也可由 AI 经文件工具直接创建/修改（写 manifest 与资源文件）；设置页列表会自动刷新，但要让 **AI 本轮对话**看到新技能/子代理，仍需新开会话或重启 App（子代理与技能清单按会话缓存）。
- manifest 解析失败或路径越界**不会拖垮其它扩展**：该扩展的问题记录在错误清单（管理页可见），对应贡献被跳过。
- 不想要某个扩展：在管理页删除，或删其目录、改名让它不被扫描；不需要逐条删技能。
