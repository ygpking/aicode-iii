# 默认模型

「设置 → 默认模型」里除了新会话使用的默认模型，还可以给几个特定用途单独指定模型。

## 识图模型

决定 AI 用哪个模型看图片。

- **跟随当前聊天模型**（默认）：用你当前选中的聊天模型看图。
- **指定专用模型**：固定用某个模型看图，不随聊天模型切换。适合聊天用的模型不支持图片、或者你想用更便宜的模型处理图片的情况。

列表里每个模型旁边会标注是否支持图片输入，供你参考。注意这里**不做强制拦截**：如果你选了一个不支持图片的模型，识图会失败，AI 会收到错误信息并自行处理（通常会提示你换一个模型）。

识图的用法上有两点值得知道：

- AI 一次最多可以给识图模型 4 到 5 张图做对比分析，之后还能在同一个识图会话里继续追问，识图模型记得之前看过的图和问答。
- 图片默认会按需压缩以节省 token，也可以要求原图直传或更省 token 的低清模式。

## 生图模型

设置 `generateImage` 工具使用的模型，支持 OpenAI 和 Gemini 兼容接口。

- OpenAI 兼容接口支持尺寸、数量、画质、背景、风格和输出格式等参数。
- Gemini 兼容接口使用模型默认尺寸与分辨率；生成多张图片时会调用多次。
- 图片默认保存到 `~/.aicode/generated-images/`，也可指定工作区路径。单张图片上限 20MB，单次调用总计上限 48MB。

## 图像模型对话生图

通过 Gemini 兼容接口接入支持图像输出的聊天模型后，可直接生成图片、上传参考图，并在后续对话中继续修改生成结果。

## 标题总结模型

新会话发出第一条消息后，AiCode 会自动给会话生成一个标题。这里可以指定专门干这件事的模型。

- **跟随当前聊天模型**（默认）。
- **指定专用模型**：建议选一个便宜快速的小模型，标题这种活不需要好模型。

标题生成在后台异步进行，不会拖慢你的对话。如果生成失败或者取不到结果，会保留系统按首句截断的临时标题，不影响使用。

生成标题用的提示词也可以自己改，方式见「自定义提示词」。

## 压缩模型

对话变长后，AiCode 会把早期的聊天内容交给一个模型总结成摘要、替掉原文——这就是上下文压缩。这里可以指定专门干这件事的模型。

- **跟随当前聊天模型**（默认）：用主聊天模型做总结。
- **指定专用模型**：固定用某个模型做总结。适合把「总结」这类不要求顶尖智力的活交给更便宜的模型。

压缩模型下面还有一项**推理等级**，控制总结时给模型多少思考预算：

- **不指定**（默认）：不发送该参数，由服务端决定。
- **较低等级**：适合压缩这类简单任务，能减少思考开销、更快出摘要。

为什么建议调低：总结对话不需要深度推理，但思考型模型可能把输出预算全花在思考上，导致摘要正文写不出来。等级调低可让预算更多用在正文上。

一点要说明：这里只提供**等级**，**不提供「关闭思考」的开关**。各家厂商关闭思考的写法互不相同（智谱用 `thinking`、千问用 `enable_thinking`、Gemini 用 `thinkingBudget`），而且有的模型是强制思考、根本关不掉；做成一个开关无法在跨模型时可靠生效，不如把能调的那一维——等级——做好。

如果压缩模型配错、Key 失效，压缩会失败。失败时 AiCode 会保留原对话不替换，并等一段时间再试（连续多次失败后停自动重试），避免反复花冤枉钱。
