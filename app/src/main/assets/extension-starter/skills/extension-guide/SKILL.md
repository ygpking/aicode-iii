# 扩展编写指南

扩展是**声明式资源包**：一个目录 + 一份 `manifest.json`，向 agent 的能力机制批量贡献技能、提示词片段、记忆、子代理与 MCP 配置。不含可执行代码，只搬资源。用户让你"做个扩展"时，按下面步骤用文件工具直接创建即可，**新开会话（或重启 App）后生效**。

## 目录约定

两级扩展根，与技能/记忆/MCP 的"全局/项目"两级一致：

```
~/.aicode/extensions/<extId>/            全局（跨项目）
<workspace>/.aicode/extensions/<extId>/  项目级（随工作区，可 git 追踪）
  ├─ manifest.json
  ├─ skills/<skill-dir>/SKILL.md
  ├─ prompts/30-<名称>.md
  ├─ memory/<name>.md
  ├─ agents/<name>.md
  └─ mcp.json
```

## manifest.json

```json
{
  "id": "my-pack",
  "name": "My Pack",
  "version": 1,
  "description": "一句话说明",
  "contributes": {
    "skills": ["skills"],
    "prompts": ["prompts"],
    "memory": ["memory"],
    "agents": ["agents"],
    "mcp": "mcp.json"
  }
}
```

- `id` 必填，`[a-z0-9-]`；非法时按目录名修正并在扩展错误中标注。
- `contributes` 各路径**相对于扩展根**，解析时校验不越界：越界的贡献被跳过、记入该扩展的错误清单，不影响其它扩展。
- 任一字段可省略：省略即不贡献该类。

## 层叠次序（近者胜）

| 层 | 优先级 |
| --- | --- |
| `prompts.custom/`（用户显式覆盖） | 最高 |
| 项目级扩展 | ↑ |
| 全局级扩展 | ↑ |
| 项目级内置目录 | ↑ |
| 全局内置目录 | 最低 |
| APK 内置资源 | 基线 |

- 技能/记忆同名：项目 > 全局、扩展 > 内置（后者胜）。
- 子代理同名：先看作用域（项目 > 全局），同作用域内扩展 > 目录。
- 提示词数字片段：custom 覆盖扩展覆盖内置；扩展的新增数字片段并入静态基线按数字排序。
- MCP server 同名：项目侧（含项目扩展）覆盖全局侧。
- `prompts.custom/.no-builtin`（完全禁用内置）不影响扩展：扩展是用户主动安装的内容，保留生效。

## 管理与故障排查

- **设置 →「AI 配置」→「扩展」**可查看已安装的扩展：按「当前项目 / 全局」分组列出名称、版本、贡献摘要与作用域；解析出错的扩展会在行内红字列出具体问题。左滑或点删除可移除整个扩展目录（不可恢复），删除后立即刷新列表。
- 扩展贡献的子代理出现在设置 →「子代理」列表（带「来自扩展」标签），可启用/停用，但**不能在设置页编辑或删除**；绕过界面直接调仓储层的改/删同样会被拒（扩展定义只读）。MCP 则更严：贡献的 server 会进「设置 → MCP」列表并参与连接，带同标签，但**完全只读**——不可编辑、不可删除，启停开关也置灰（启用状态写在扩展包的 mcp.json 里，要停用就改那里或卸载该扩展）。
- manifest 解析失败或路径越界**不会拖垮其它扩展**：该扩展的问题记录在错误清单（管理页可见），对应贡献被跳过。
- 不想要某个扩展：在管理页删除，或删其目录、改名让它不被扫描；不需要逐条删技能。
- 扩展目录被增删改后，设置页的技能/记忆/子代理/扩展列表会在数秒内自动刷新（无需重进页面）。

## 给 AI 的实操要点

1. 创建扩展 = 用文件工具写 manifest.json + 资源文件，路径选全局根（跨项目）或项目根（随仓库分发）。
2. SKILL.md 的 frontmatter 必须含 `name` 与 `description`（description 是触发判据，写清"何时使用"）；记忆 md 同理（可加 `kind: trace|policy|skill`）；子代理定义 `agents/<name>.md` 用 frontmatter 配 provider/model/tools 等，**正文即系统提示词**（正文空则定义非法被跳过）。
3. 写完提醒用户：设置页列表会自动刷新，但**要让 AI 本轮对话看到新技能/子代理，需重启 App 或新开会话**（清单按会话缓存）。
4. 本扩展自身（extension-starter）就是最小可运行样例，可对照其目录结构。
