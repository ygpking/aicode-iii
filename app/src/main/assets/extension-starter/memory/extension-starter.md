# 内置示例扩展自检

本文件由 APK 内置的示例扩展 `extension-starter` 贡献（首次启动时释放到 `~/.aicode/extensions/extension-starter/`）。

它出现在记忆清单里 = 扩展的记忆贡献链路正常；同时技能清单里应能看到 `extension-guide` 技能（问"怎么写扩展"即可触发）。两者都不可见时检查扩展目录与 manifest。
